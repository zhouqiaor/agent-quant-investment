# QuantPilot · 产品经理视角总结

> 文档版本 v1.0 | 适用于产品评审、季度 OKR 对齐、投资人汇报

---

## 1. 产品愿景与价值主张

### 1.1 三句话价值主张
1. **降低门槛**：把"写代码才能做量化"变成"拖拖拽拽就行"
2. **闭环验证**：从想法到验证无需切换工具，全部在小程序内完成
3. **数据驱动**：A/B 实验 + AI 诊断，让"决策有依据"

### 1.2 北极星指标
- **周活跃策略迭代次数**（反映用户真实使用深度）

## 3. 界面交互体验分析

### 3.1 信息架构（6 大 Tab）

```
┌────────────────────────────────────────────────────┐
│  首页 │ 行情 │ 策略 │ 交易 │ 报告 │ 我的            │
└────────────────────────────────────────────────────┘
   ↓     ↓     ↓      ↓      ↓      ↓
 速览  自选   列表   持仓   AI    个人
       推送   详情   流水   诊断  设置
```

### 3.2 核心交互流（用户旅程）

#### 流 1：新用户首日
```
打开 App → 首页"AI 诊断"卡片 → 进入"AI 报告" → 看示例报告
→ 弹窗引导"建你的第一个策略" → 选模板 → 一键 fork → 跑通
```
**预期**：3 分钟内完成首个回测

#### 流 2：策略研究员工作日
```
策略页 → 打开 v3 → 点"Fork" → 改参数 → 保存为 v4
→ 点"A/B 对比" → 选 v3/v4 + 同标的 → 跑 1 周
→ 看对比面板 → 点"胜出方 Fork 为新基线"
```
**预期**：5 分钟完成一次完整调参循环

### 3.3 体验亮点
- **可逆**：所有操作可撤销（Fork 是新版本，旧版不动）
- **可对比**：任意两个版本可 A/B
- **可解释**：AI 给出诊断理由，不只是结论

### 3.4 体验待优化（PM 已识别）
- [ ] 暗色/亮色主题切换（V1.1）
- [ ] H5 端快捷键（V2.0）
- [ ] Service Worker 离线缓存（V2.0）
- [ ] 推送渠道扩展（短信 / 微信服务通知）
- [ ] 教程新手引导（V1.1）

✅ 已支持 | ⏳ 规划中 | 部分 部分支持 | ❌ 不支持

### 4.2 我们的差异化

**唯一性**：
1. 唯一一款"小程序形态 + A/B 实验 + AI 诊断"三合一的量化工具
2. 唯一开源 + 免费的端到端"策略工厂"
3. 唯一把"验证"做成第一公民（其他产品都把"交易"做第一公民）

**借鉴点**：
- 借鉴雪球的"组合净值时间轴"展示
- 借鉴聚宽的"研究-回测-模拟-实盘"四阶段流水
- 借鉴 Wealthfront 的"AI 给建议"交互范式
- 借鉴 Freqtrade 的"参数优化目标函数"

**避免的坑**：
- ❌ 不做"千人千面"（量化用户喜欢确定性）
- ❌ 不强推实盘（合规优先，先把研究体验做到极致）
- ❌ 不绑券商（避免商业利益冲突）

## 5. 风险与合规

### 5.1 合规红线
- **明确"非投资建议"**：所有页面顶部声明
- **不接实盘**：避免持牌问题
- **不诱导交易**：避免"暗示收益"话术
- **开源透明**：审计友好

### 5.2 业务风险
| 风险 | 缓解措施 |
|------|----------|
| 数据源中断 | 多源适配层（V1.1）+ TOS 缓存 |
| 用户误用模拟盘当实盘 | UI 强提示 + 颜色区分 |
| LLM 幻觉给错误建议 | AI 输出加"非投资建议"水印 + 置信度展示 |
| 行业政策变化 | 紧盯证监会公告，及时下架相关功能 |
