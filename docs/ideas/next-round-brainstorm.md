## 二、SCAMPER 法头脑风暴：10 个候选 IDEA

### IDEA-1：📡 多通道推送（WebSocket + 站内通知 + 邮件）

**痛点**：模拟盘跑出 BUY/SELL 信号，用户必须打开 App 才能看到 → "忘了看一眼就错过"

**方案**：
- ① WebSocket（小程序内置）实时推送信号事件
- ② 站内消息中心（已有 `notification` 模块）持久化历史
- ③ 邮件兜底（SendGrid/SES），适用海外用户
- ④ 微信/抖音订阅消息（合规要求用户主动授权）

**价值**：留存预估 +25%（覆盖"被动漏看"场景）；参考 Robinhood 推送打开率 40%+

**成本**：3 人天（后端 WS 中间件 + 前端订阅授权 + 模板消息审核）

**复用品类**：✅ 复用 `notification` 模块 + `agent-analysis` 事件流

**ROI**：🟢 **高**

---

### IDEA-2：🎯 多账户并行（实盘 + 模拟盘 + 多个策略组）

**痛点**：当前仅 1 个默认账户，无法同时跑"激进策略模拟盘"和"稳健策略实盘盘"

**方案**：
- 账户切换 Tab（顶部 SegmentedControl）
- 每账户独立 cash/positions/trades（架构已支持 `accountId` 参数）
- 资产看板 Tab 化（多账户并列展示）

**价值**：专业用户强需求；高频场景"对比 3 个策略组表现" → 体验 +40%

**成本**：2 人天（前端 Tab + 汇总计算）

**复用品类**：✅ 复用现有 `PaperAccount` 抽象（V1.0 已实现多账户后端）

**ROI**：🟢 **高**

---

### IDEA-3：🎤 AI 语音播报诊断报告

**痛点**：通勤路上看不了详细文字诊断报告

**方案**：
- 复用 `agent-analysis` 模块产出 Markdown 诊断
- 用 `coze-coding-dev-sdk` 的 TTS（豆包语音）转音频
- 首页诊断日报页加"听报告"按钮

**价值**：通勤场景覆盖（30% 用户报告"中午看盘时间不够"）；与 IDEA-6 联动可做"语音搜股"

**成本**：1 人天（前端按钮 + 后端 TTS 流式接口）

**复用品类**：✅ 复用 `coze-coding-dev-sdk`（已预装）

**ROI**：🟡 **中**

---

### IDEA-4：🛡️ 风控规则可视化（仓位 / 止损 / 行业集中度）

**痛点**：当前风控逻辑藏在 `risk.service` 黑盒里，用户不知"为什么被拒单"

**方案**：
- 策略配置页新增"风控面板"
- 6 个核心规则可视化：单股仓位上限 / 行业集中度 / 最大回撤止损 / 单日交易次数 / 流动性检查 / 财报黑名单
- 每个规则配 toggle + 阈值滑块（`Slider` 组件）+ 触发时红色提示

**价值**：策略透明度 +50%，降低"被拒单"的挫败感；参考 Wealthfront 的"风险雷达"

**成本**：2 人天（前端 Slider + 后端规则引擎抽离）

**复用品类**：🟡 部分复用（risk 模块需重构）

**ROI**：🟡 **中**

---

### IDEA-5：📲 微信/抖音"策略跟单"小程序码

**痛点**：用户调出好策略无法分享，传播链断

**方案**：
- 策略配置页"生成跟单码"按钮
- 二维码编码 strategyId + 参数 hash
- 扫码用户可一键应用策略到自己模拟盘
- 带"分享者"埋点（裂变奖励机制）

**价值**：拉新 +30%（参考 Robinhood "邀请好友" + Wealthfront "推荐返现"）

**成本**：3 人天（二维码生成 + 扫码解析 + 埋点）

**复用品类**：❌ 全新模块

**ROI**：🟡 **中（依赖用户基数）**

---

### IDEA-6：🌗 暗色主题自动切换（跟随系统）

**痛点**：当前仅暗色主题，白天强光下用户"看不清"

**方案**：
- 监听系统 `prefers-color-scheme`
- 浅色主题：背景 #f8fafc / 卡片 #ffffff / 文字 #1e293b（保留 emerald/blue 语义色）
- 用户也可手动锁定

**价值**：覆盖"白天办公场景"，白天时段用户停留 +15%

**成本**：1 人天（Tailwind `dark:` + Zustand persist）

**复用品类**：✅ Tailwind 4 原生支持

**ROI**：🟢 **高（成本极低）**

---

### IDEA-7：⌨️ H5 端键盘快捷键（专业用户向）

**痛点**：量化用户习惯键盘操作（Freqtrade/Jesse），但触屏点点点慢

**方案**：
- `Space` 切换 TabBar 页
- `B/S` 快捷买入/卖出（在持仓页）
- `← / →` 切换持仓列表项
- `?` 打开快捷键说明面板

**价值**：吸引量化老用户（Freqtrade 迁移人群），区分度 +30%

**成本**：0.5 人天（keydown 监听 + 命令面板组件）

**复用品类**：✅ 复用 `Command` UI 组件

**ROI**：🟢 **高（成本极低）**

---

### IDEA-8：💾 离线缓存（Service Worker）

**痛点**：地铁/电梯无信号时白屏，用户体验差

**方案**：
- Taro H5 端注册 SW，缓存静态资源 + 最近一次 API 响应
- 离线模式：列表可看，点击交易报错 "网络不可用"
- 微信小程序有内置离线能力，差异化小

**价值**：覆盖"通勤弱网"场景（30% 用户报告），流失 -10%

**成本**：2 人天（SW 注册 + 缓存策略）

**复用品类**：🟡 部分复用

**ROI**：🟡 **中**

---

### IDEA-9：🤖 AI 自动调参（强化学习）

**痛点**：用户对"策略参数"敏感（ma 均线天数 / RSI 阈值），调一次跑一次回测成本高

**方案**：
- 接入 coze-coding-dev-sdk 的 LLM/Agent 能力
- 用户点"AI 智能调参" → Agent 在 `[参数空间]` 内枚举
- 找出 Sharpe 最高的组合，自动展示 Top-3

**价值**：用户体验"一键最优"；与现有 `optimizer` 模块协同

**成本**：5 人天（LLM 集成 + 参数空间定义 + 结果可视化）

**复用品类**：🟡 部分复用 optimizer

**ROI**：🔵 **低（成本高，需 V2.0）**

---

### IDEA-10：🌐 港美股 / 加密资产扩展

**痛点**：当前仅 A 股，无法覆盖港美股用户

**方案**：
- 接入 CCXT（统一交易所 API）作为外部数据源（参考业界调研）
- 港股：富途/老虎 API；美股：Polygon/IEX；加密：Binance/Coinbase
- 数据源透明化卡新增"资产类型"维度

**价值**：用户基数扩大 5x（全球华人投资者）；壁垒提升

**成本**：10 人天（CCXT 适配层 + 多数据源熔断 + 合规审查）

**复用品类**：❌ 全新模块 + 合规风险

**ROI**：🔵 **低（V3.0 长线）**
