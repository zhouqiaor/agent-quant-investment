## 🔍 数据流细节

### 1. 实时行情数据来源（可信）

**来源**：新浪财经 API (`hq.sinajs.cn`)
- **获取方式**：`MarketService.fetchRealtimeData()`
- **缓存策略**：5s 缓存（`Cache-Control` header）
- **数据字段**：
  - `name`：股票名称（GBK 转 UTF-8）
  - `price`：最新价
  - `changePercent`：涨跌幅
  - `open/high/low/volume`：开盘价、最高价、最低价、成交量
- **数据验证**：`price > 0` 才标记为有效

### 2. 持仓数据处理（当前仅内存）

**处理链**：
```
新浪行情 → LivePnlService.onTick() 
         → PaperTradingService.markPrices(prices)
         → 重算持仓 currentPrice/marketValue/pnl/pnlRate
         → 重算账户 totalValue/totalPnl/totalPnlRate
```

**显示**：
- 前端 `/api/paper-trading/positions`
- 前端 `/api/paper-trading/account`
- 前端 `/api/paper-trading/position/:symbol`

### 3. 交易记录处理（当前仅内存）

**触发来源**：
1. 手动交易：`POST /api/paper-trading/manual/buy/sell`
2. 自动交易：策略信号触发 `executeSignal()`
3. 回测回放：`PortfolioBacktestService` 模拟

**记录字段**：
- `id`：交易 ID（UUID）
- `type`：BUY/SELL
- `symbol/name`：股票代码/名称
- `price/quantity/amount`：价格/数量/金额
- `reason`：交易原因
- `strategyId`：关联策略
- `date/time`：日期/时间

**显示**：
- 前端 `/api/paper-trading/trades`（支持按 type/symbol 过滤）
- 前端 `/api/paper-trading/summary`（交易统计）

## 🔬 可信度评估

### ✅ 可信部分

1. **行情数据**：
   - 来源：新浪财经（权威数据源）
   - 缓存：5s 合理间隔
   - 验证：价格有效性检查

2. **策略逻辑**：
   - 确定性：条件求值无随机性
   - 可复现：相同输入 → 相同信号
   - 可测试：TDD 覆盖 162 个用例

3. **计算逻辑**：
   - 清晰：持仓重估、盈亏计算逻辑透明
   - 精确：保留 2 位小数
   - 幂等：相同输入 → 相同输出

### ⚠️ 需要改进

1. **数据持久化缺失**：
   - 风险：服务重启 → 持仓/交易记录全部丢失
   - 修复：集成 SQLite 持久化

2. **账户隔离不完善**：
   - 当前：单一默认账户 `default`
   - 改进：支持多账户隔离（回测已支持）

## 📋 修复优先级

1. **P0 高优先级**：持仓/交易记录持久化
2. **P1 中优先级**：账户快照/备份/恢复
3. **P2 低优先级**：多账户完整支持
