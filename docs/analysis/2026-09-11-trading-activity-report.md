`market_ticks` 表中 price 和 changePercent **全部为 0**（沙箱网络限制，Sina 实时 API 不可达）。

### 2.2 间接原因：策略触发条件不满足

最近 10 笔交易（2026-09-08 ~ 09-10）触发原因全部是：
> "changePercent 小于 触发买入信号 | 当前跌幅"

需要 `changePercent < 0` 才会触发，但当前 changePercent = 0，所以**没有任何新信号**。

### 2.3 系统行为

- MarketPollingService 在跑（每 5s 拉一次）
- TickRecorder 在录数据（仅价格=0）
- SignalService 调策略时，因 `changePercent = 0`，既不触发买入也不触发卖出
- 没有信号 → 没有下单 → 没有新交易

**结论：系统健康运行，但因外部数据源不可达，业务链处于"无信号"的静默期。**
