# SPEC — 100 账户实时仿真系统

> v1.0 | 目标：今晚 19:00 启动，明天 09:00 出报告

## 1. 目标

**一句话**：一键创建 100 个虚拟账户，各按行业专注+随机策略独立运行，24 小时后给出投资结果统计报告。

**核心价值**：
- 用 100 个独立 agent 模拟不同人群的投资决策
- 行业聚焦 → 看哪个行业 alpha 最高
- 策略随机化 → 看哪个策略胜率最高
- 资金随机化 → 看资金规模是否影响收益

## 2. 账户画像矩阵

| 维度 | 范围 | 随机方法 |
|------|------|----------|
| 初始资金 | 1万 ~ 100 万 | log-uniform 分布 |
| 行业专注 | 11 个行业随机 1-3 个 | 等概率 |
| 股票池 | 行业下全部股票（1-5 只） | 全选 |
| 策略类型 | 5 种（均线/动量/反转/突破/跟随） | 等概率 |
| 参数扰动 | 每个参数 ±20% | uniform |
| 风险偏好 | 保守/中性/激进 | 0.2/0.6/0.2 |
| 交易频率 | 1-5 次/小时 | uniform |

**共 11 行业 × 13 股票 = 充分覆盖**

## 4. 调度策略

- **tick 间隔**：30s（vs 真实 polling 5s；让 100 账户有足够决策时间）
- **决策顺序**：按账户 ID 顺序串行（避免锁竞争）
- **决策流程**：
  1. 获取账户当前现金+持仓
  2. 获取关注股票最新价（真实→无则用合成价）
  3. 策略逻辑判定（BUY/SELL/HOLD）
  4. 风险检查（仓位上限、单日次数、止损）
  5. 通过 → 模拟下单；失败 → 跳过
- **行情源策略**：真实 Sina 优先，无则用合成 walk（5% 标准差）

## 5. 数据模型

```sql
simulation_runs         -- 仿真任务主表
account_snapshots       -- 账户每小时快照
simulation_trades       -- 仿真产生的所有交易
```

**为什么不复用 paper_trades**：仿真数据隔离，避免污染生产数据。

## 6. 报告维度（明天输出）

| 维度 | 指标 |
|------|------|
| 整体 | 平均/中位/分位数收益、最大回撤、Sharpe |
| 行业 | 各行业平均收益、夏普、胜率 |
| 策略 | 各策略胜出率、参数敏感性 |
| 资金 | 资金规模 vs 收益关系 |
| Top/Bottom | Top10 / Bottom10 账户画像 |

## 7. UI 设计

**页面**：`src/pages/simulation/index.tsx`
- 顶部：仿真启动按钮 / 运行状态卡（运行中 X 分钟）
- 中部：实时净值排行榜（前 20 / 后 20）
- 底部：24h 趋势对比（Top3 vs Bottom3 净值曲线）
- 第二天：自动切换为报告视图

## 8. 时间线

| 时间 | 动作 |
|------|------|
| T+0  | 创建 100 账户 |
| T+0  | 启动调度器 |
| T+1h | 第一份快照 |
| T+24h | 停止 + 报告生成 |
| T+24h | 推送报告到 UI |

## 9. 风险与降级

- 单账户最大持仓占比 50%
- 单股最大占比 30%
- 单日交易次数上限 50
- 持仓总额超 100 万强制减仓 20%
- 现金为负时账户冻结
